# Code evaluation
## AI 
The AI evaluation agent could evaluate the coding exercises according to the instructions and the code itself. 
It could also potentially use the test cases and outputs provided earlier to make sure the answers pass the tests.

## Tests
Our application primarily uses this approach. The teacher can create a coding exercise with the function name, and input and output
values for the function. Then the student (or teacher during evaluation) can run the code calling the function, and see if the tests are passed.
The AI agent made for creating exercises is also able to create these types of coding exercises.

## Heuristics
The code can still be evaluated manually, in case a different language is supposed to be used, for example. 
You can still write different coding languages in the coding task box, even though the automatic test cases etc. will not work.
If formatting, naming etc. is important, it's also better to manually go through the code, rather than let test cases and AI determine everything.
